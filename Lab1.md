## Задание 1. Методы

### Задача 1. Дробная часть

**Текст задачи**

Дана сигнатура метода: `public double fraction(double x);`

Необходимо реализовать метод таким образом, чтобы он возвращал только дробную часть числа `x`. Вещественное число может быть преобразовано к целому путём отбрасывания дробной части.

**Алгоритм решения**

Для получения дробной части необходимо преобразовать исходное вещественное число к целому типу `int`, после чего вычесть полученное целое значение из исходного числа. Результат вычитания и будет дробной частью числа.

### Задача 2. Букву в число

**Текст задачи**

Дана сигнатура метода: `public int charToNum(char x);`

Метод принимает символ `x`, который представляет собой одну из цифр от `0` до `9`. Необходимо реализовать метод таким образом, чтобы он преобразовывал символ в соответствующее число. Код символа `0` равен числу 48.

**Алгоритм решения**

Из кода принятого символа вычитается код символа `0`. Поскольку символы цифр в таблице Unicode расположены последовательно, разность кодов позволяет получить соответствующее числовое значение.

### Задача 3. Двузначное

**Текст задачи**

Дана сигнатура метода: `public bool is2Digits(int x);`

Необходимо реализовать метод таким образом, чтобы он принимал число `x` и возвращал `true`, если оно двузначное, и `false` в противном случае.

**Алгоритм решения**

Проверяется, находится ли число в диапазоне от 10 до 99 или от -99 до -10. Если выполняется одно из этих условий, число является двузначным. В противном случае возвращается `false`.

### Задача 4. Диапазон

**Текст задачи**

Дана сигнатура метода: `public bool isInRange(int a, int b, int num);`

Метод принимает левую и правую границы (`a` и `b`) некоторого числового диапазона. Необходимо реализовать метод таким образом, чтобы он возвращал `true`, если `num` входит в указанный диапазон, включая границы. При этом заранее неизвестно, какая из границ больше.

**Алгоритм решения**

Сначала определяется минимальное и максимальное значения среди `a` и `b`. Затем проверяется, находится ли число `num` между этими значениями включительно. Если условие выполняется, метод возвращает `true`, иначе — `false`.

### Задача 5. Равенство

**Текст задачи**

Дана сигнатура метода: `public bool isEqual(int a, int b, int c);`

Необходимо реализовать метод таким образом, чтобы он возвращал `true`, если все три полученных методом числа равны.

**Алгоритм решения**

С помощью оператора сравнения проверяется равенство первого и второго чисел, а также второго и третьего чисел. Если оба условия выполняются одновременно, возвращается `true`. В противном случае возвращается `false`.

## Задание 2. Условия

### Задача 1. Модуль числа

**Текст задачи**

Дана сигнатура метода: `public int abs(int x);`

Необходимо реализовать метод таким образом, чтобы он возвращал модуль числа `x`: если число положительное, оно остаётся таким же, если отрицательное — необходимо вернуть его без знака минус.

**Алгоритм решения**

Используется метод `Math.abs()`, который возвращает абсолютное значение переданного числа. Если число отрицательное, знак меняется на положительный. Если число положительное или равно нулю, оно остаётся без изменений.

### Задача 2. Тридцать пять

**Текст задачи**

Дана сигнатура метода: `public bool is35(int x);`

Необходимо реализовать метод таким образом, чтобы он возвращал `true`, если число `x` делится нацело на 3 или 5. При этом, если оно делится и на 3, и на 5, необходимо вернуть `false`. Для проверки делимости используется оператор `%`.

**Алгоритм решения**

Сначала проверяется делимость числа на 3 и на 5 с помощью оператора остатка от деления. Затем результаты проверок сравниваются с помощью логического исключающего ИЛИ. Метод возвращает `true`, если выполняется только одно из двух условий, и `false`, если выполняются оба условия или ни одно из них.

### Задача 3. Тройной максимум

**Текст задачи**

Дана сигнатура метода: `public int max3(int x, int y, int z);`

Необходимо реализовать метод таким образом, чтобы он возвращал максимальное из трёх полученных методом чисел. Идеальное решение включает всего две инструкции `if` и не содержит вложенных `if`.

**Алгоритм решения**

В качестве начального максимального значения принимается первое число. Затем оно сравнивается со вторым числом, и при необходимости максимальное значение обновляется. После этого аналогичная проверка выполняется для третьего числа. В конце метод возвращает найденное максимальное значение.

### Задача 4. Двойная сумма

**Текст задачи**

Дана сигнатура метода: `public int sum2(int x, int y);`

Необходимо реализовать метод таким образом, чтобы он возвращал сумму чисел `x` и `y`. Однако, если сумма попадает в диапазон от 10 до 19 включительно, необходимо вернуть число 20.

**Алгоритм решения**

Сначала вычисляется сумма двух переданных чисел. Затем проверяется, находится ли результат в диапазоне от 10 до 19 включительно. Если условие выполняется, возвращается 20. В противном случае возвращается вычисленная сумма.

### Задача 5. День недели

**Текст задачи**

Дана сигнатура метода: `public String day(int x);`

Метод принимает число `x`, обозначающее день недели. Необходимо реализовать метод таким образом, чтобы он возвращал строку с названием соответствующего дня недели, где 1 — понедельник, а 7 — воскресенье. Если число не находится в диапазоне от 1 до 7, необходимо вернуть текст «это не день недели». Вместо `if` в данной задаче необходимо использовать `switch`.

**Алгоритм решения**

Для выбора названия дня недели используется оператор `switch`. Каждому числу от 1 до 7 соответствует определённое название дня. Если переданное значение не совпадает ни с одним из вариантов, выполняется ветка `default`, возвращающая сообщение о некорректном дне недели.

## Задание 3. Циклы

### Задача 1. Числа подряд

**Текст задачи**

Дана сигнатура метода: `public String listNums(int x);`

Необходимо реализовать метод таким образом, чтобы он возвращал строку, в которой будут записаны все числа от 0 до `x` включительно.

**Алгоритм решения**

Создаётся объект `StringBuilder` для формирования результирующей строки. С помощью цикла `for` перебираются числа от 0 до `x` включительно. Каждое число добавляется в строку через пробел. После завершения цикла возвращается полученная строка.

### Задача 2. Чётные числа

**Текст задачи**

Дана сигнатура метода: `public String chet(int x);`

Необходимо реализовать метод таким образом, чтобы он возвращал строку, в которой записаны все чётные числа от 0 до `x` включительно. Для обеспечения качества кода инструкцию `if` использовать не следует.

**Алгоритм решения**

Создаётся объект `StringBuilder` для формирования строки. Цикл `for` начинается с числа 0 и выполняется до значения `x` включительно. На каждой итерации счётчик увеличивается на 2, поэтому перебираются только чётные числа. Все найденные значения добавляются в результирующую строку через пробел.

### Задача 3. Длина числа

**Текст задачи**

Дана сигнатура метода: `public int numLen(long x);`

Необходимо реализовать метод таким образом, чтобы он возвращал количество знаков в числе `x`.

**Алгоритм решения**

Сначала число преобразуется в положительное значение, чтобы знак минус не учитывался при подсчёте цифр. Затем проверяется особый случай — число 0, длина которого равна 1. Для остальных чисел с помощью цикла `while` число последовательно делится на 10 до тех пор, пока не станет равно нулю. На каждой итерации счётчик увеличивается на единицу. Полученное значение возвращается в качестве результата.

### Задача 4. Квадрат

**Текст задачи**

Дана сигнатура метода: `public void square(int x);`

Необходимо реализовать метод таким образом, чтобы он выводил на экран квадрат из символов `*` размером `x`, у которого `x` символов в ряд и `x` символов в высоту.

**Алгоритм решения**

Для построения квадрата используются два вложенных цикла `for`. Внешний цикл отвечает за количество строк, а внутренний — за количество символов `*` в каждой строке. После завершения внутреннего цикла выполняется переход на новую строку. В результате выводится квадрат размером `x` на `x`.

### Задача 5. Правый треугольник

**Текст задачи**

Дана сигнатура метода: `public void rightTriangle(int x);`

Необходимо реализовать метод таким образом, чтобы он выводил на экран треугольник из символов `*`, у которого `x` символов в высоту, а количество символов в ряду совпадает с номером строки. При этом треугольник должен быть выровнен по правому краю. Перед символами `*` необходимо выводить нужное количество пробелов.

**Алгоритм решения**

Используются два вложенных цикла. Внешний цикл перебирает строки треугольника. Первый внутренний цикл выводит необходимое количество пробелов, которое уменьшается с каждой новой строкой. Второй внутренний цикл выводит символы `*`, количество которых соответствует номеру текущей строки. После каждой строки выполняется переход на новую строку.

## Задание 4. Массивы

### Задача 1. Поиск первого значения

**Текст задачи**

Дана сигнатура метода: `public int findFirst(int[] arr, int x);`

Необходимо реализовать метод таким образом, чтобы он возвращал индекс первого вхождения числа `x` в массив `arr`. Если число не входит в массив, возвращается `-1`.

**Алгоритм решения**

С помощью цикла `for` последовательно перебираются все элементы массива от начала до конца. Каждый элемент сравнивается с искомым числом `x`. При первом совпадении метод возвращает индекс найденного элемента. Если после завершения цикла совпадение не обнаружено, возвращается `-1`.

### Задача 2. Поиск максимального

**Текст задачи**

Дана сигнатура метода: `public int maxAbs(int[] arr);`

Необходимо реализовать метод таким образом, чтобы он возвращал наибольшее по модулю, то есть без учёта знака, значение массива `arr`.

**Алгоритм решения**

В качестве начального максимального элемента выбирается первый элемент массива. Затем с помощью цикла `for` перебираются остальные элементы. Для каждого элемента вычисляется абсолютное значение и сравнивается с абсолютным значением текущего максимального элемента. Если найдено большее значение по модулю, текущий максимум заменяется. После завершения перебора возвращается сам элемент массива, имеющий наибольший модуль.

### Задача 3. Добавление массива в массив

**Текст задачи**

Дана сигнатура метода: `public int[] add(int[] arr, int[] ins, int pos);`

Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, который будет содержать все элементы массива `arr`, однако в позицию `pos` будут вставлены значения массива `ins`.

**Алгоритм решения**

Создаётся новый массив, размер которого равен сумме размеров исходного массива `arr` и вставляемого массива `ins`. Сначала в новый массив копируются элементы `arr`, расположенные до позиции вставки `pos`. Затем последовательно копируются все элементы массива `ins`. После этого копируются оставшиеся элементы исходного массива `arr`, начиная с позиции `pos`. В результате возвращается новый массив с вставленными элементами.

### Задача 4. Возвратный реверс

**Текст задачи**

Дана сигнатура метода: `public int[] reverseBack(int[] arr);`

Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, в котором значения массива `arr` записаны задом наперёд.

**Алгоритм решения**

Создаётся новый массив той же длины, что и исходный. С помощью цикла `for` элементы исходного массива копируются в новый массив в обратном порядке. Индексу первого элемента нового массива соответствует последний элемент исходного массива, индексу второго — предпоследний и так далее. После завершения копирования возвращается новый массив.

### Задача 5. Все вхождения

**Текст задачи**

Дана сигнатура метода: `public int[] findAll(int[] arr, int x);`

Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, в котором записаны индексы всех вхождений числа `x` в массив `arr`.

**Алгоритм решения**

Сначала выполняется перебор исходного массива для подсчёта количества элементов, равных числу `x`. На основе полученного количества создаётся новый массив необходимого размера. Затем исходный массив перебирается повторно. Если текущий элемент равен `x`, его индекс записывается в новый массив. После завершения перебора возвращается массив со всеми найденными индексами.
